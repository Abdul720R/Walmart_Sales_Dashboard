# 📊 Walmart Sales Analysis & Performance Dashboard

Welcome to the **Walmart Sales Analysis Dashboard** project! This repository contains a dynamic and interactive Power BI dashboard designed to analyze retail sales performance, customer demographic trends, store-level metrics, and key performance indicators (KPIs) for Walmart.

---

## 📌 Project Overview

The objective of this project is to transform raw retail data into actionable business insights using Power BI. The dashboard helps stakeholders and business managers track overall sales, profit margins, product category performance, and geographic regional trends to make data-driven decisions.

---

## ✨ Key Features & Insights

- **Executive Summary:** High-level KPIs including Total Revenue, Total Profit, Total Units Sold, and Average Order Value (AOV).
- **Sales & Trend Analysis:** Time-series analysis showing monthly, quarterly, and yearly sales trajectories.
- **Store & Regional Performance:** Breakdown of top-performing stores and regional market analysis.
- **Product Category Insights:** In-depth view of top product categories, customer demand, and profit contribution.
- **Interactive Filters (Slicers):** Dynamic filtering by Date Range, Store Location, Product Category, and Region.

---

## 🛠️ Tech Stack & Tools Used

- **Power BI Desktop:** Dashboard design, Data Modeling, DAX measures, and Visualizations.
- **Power Query:** Data Extraction, Transformation, and Loading (ETL).
- **DAX (Data Analysis Expressions):** Calculated columns, custom KPIs, and time-intelligence functions.
